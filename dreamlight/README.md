# 小芽与风的种子 · Dreamlight

五集动画短片：一个五岁女孩视角的梦幻世界，与现实融合、对抗、领悟。
手绘日式动画长片风格，原创角色与故事。**画面、动画、字幕、配乐 100% 由代码生成**——
没有任何图片素材，也不依赖任何生图模型。

- 在线观看：`/dreamlight/`（GitHub Pages）
- 剧本与世界观：[story/BIBLE.md](story/BIBLE.md)

## 怎么用

```bash
# 本地预览
python3 -m http.server 8000      # 打开 http://localhost:8000/dreamlight/

# 导出 MP4（1280×720 / 24fps / 带配乐），需要 Playwright + ffmpeg
node tools/render.cjs          # 全部五集 -> out/
node tools/render.cjs 3        # 只导第三集
```

所有台词、时长、镜头运动、特效和灰度都写在 `episodes.js` 里，改这一个文件就能重新出片。

## 代码是怎么“手绘”的

| 文件 | 负责 |
|---|---|
| `paint.js` | 水粉纸纹与笔触纹理、积云（球体并集高度场 → 模糊法线 → 赛璐璐分层上色）、树冠叶团、草地、砖墙、窗户/防盗窗/空调外机、电线杆、湿地面倒影；最后给每个画层加一道低频扭曲，让直线像手绘一样微微起伏 |
| `chars.js` | 人物是一笔一笔“写”出来的曲线画：每个部件用 SVG 路径描述，平涂赛璐璐底色 + 手工摆放的阴影形状；描线由“墨线渲染器”生成——线宽随笔压变化、开放笔画两端收锋、带轻微手抖；手臂是会弯曲的袖子，有肘部褶皱和画出来的手指 |
| `scenes.js` | 19 个场景（雨天街道、会呼吸的老楼、屋顶菜园、雾中城市、拆迁工地、黄昏飞行……），每个场景分远/中/近三层，静态层只画一次并缓存 |
| `engine.js` | 多层视差镜头、角色按场景光线染色、雨/雾/蒲公英种子/萤火虫等粒子、柔光 + 纸纹 + 暗角的“胶片”收尾、标题与字幕、WebAudio 八音盒配乐 |
