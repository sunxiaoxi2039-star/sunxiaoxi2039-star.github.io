# 《小芽与风的种子》系列圣经

> 一个五岁女孩视角的梦幻世界：与现实**融合**、与现实**对抗**、最后**领悟**。
> 五集短片，每集约 1 分钟。手绘水彩质感的日式动画长片美术风格（原创角色、原创故事）。
> 制作方式：只用 **GPT 生图** + **代码**。

## 一句话

五岁的小芽在雨天的水洼里遇见了风的种子「絮絮」。外婆的老楼要被拆了，灰雾吞掉了城市的颜色。她用一个孩子的方式去保护、去战斗，最后明白：会离开的东西，也会换一种样子留下来。

## 核心设定：世界有两层

| 现实层（大人看见的） | 梦境层（小芽看见的） | 它真正的意思 |
|---|---|---|
| 雨天的水洼 | 通往晴空的门 | 孩子的想象力就在脚边 |
| 红绿灯、汽车 | 灯笼、打呼噜的甲虫 | 城市其实也是活的 |
| 外婆住的老筒子楼 | 会呼吸、会眨眼的「老楼」 | 被爱过的地方有灵魂 |
| 墙上的「拆」字 | 流着红色眼泪的怪兽脸 | 孩子第一次面对失去 |
| 大人的焦虑、疲惫 | 吃掉颜色的「灰雾」/「灰先生」 | 情绪会改变世界的颜色 |
| 挖掘机 | 铁犀牛 | 「敌人」也只是被派来的人 |
| 蒲公英 | 絮絮 —— 风的种子 | 告别，是为了在别处开花 |

**规则**：梦境层从不推翻现实层。老楼最终还是拆了，外婆还是老了。孩子赢得的不是结果，而是看待结果的方式。

## 角色

- **小芽**（5 岁）：黑色齐刘海短发、苹果脸、黄雨衣、红雨靴、随身一袋蜡笔。勇敢但不鲁莽；生气时会握紧小拳头。
- **絮絮**：一团蒲公英绒毛做成的风之精灵，西瓜大小，两颗黑珠子眼睛，头顶一片绿叶。小芽勇敢一点，它就长大一点；小芽难过，它就缩小。最后化作一千颗种子散向城市。
- **外婆**：银发盘髻、圆框眼镜、靛蓝棉袄、碎花围裙。在老楼屋顶种番茄和向日葵。
- **妈妈**：三十出头，米色风衣、工牌、黑眼圈。一个人扛着工作和外婆的病，她的眼泪就是灰雾的源头。
- **老楼**：五层红砖筒子楼，绿阳台、晾衣绳、鸽子。二楼两扇窗是它的眼睛，门洞是它的嘴，会随呼吸起伏。
- **灰先生**：雾和烟尘组成的高大无脸人，戴一顶雾做的高礼帽。说话永远是「没用的」。
- **铁犀牛**：被想象成机械犀牛的黄色挖掘机，大灯是眼睛，铲斗是角。
- **司机叔叔**：橙色反光背心、黄安全帽，驾驶室里夹着女儿的照片。

## 五集结构

| 集 | 标题 | 阶段 | 情感曲线 |
|---|---|---|---|
| 1 | 雨天的水洼 | 融合 | 孤单 → 惊奇 → 被陪伴 |
| 2 | 会呼吸的老楼 | 融合 | 温暖 → 不安 → 决心 |
| 3 | 灰雾来了 | 对抗 | 委屈 → 反击 → 正面冲突 |
| 4 | 铁犀牛与外婆的窗 | 对抗 → 转折 | 愤怒 → 动摇 → 理解 |
| 5 | 风的种子 | 领悟 | 不舍 → 告别 → 平静的希望 |

### 第一集 · 雨天的水洼
幼儿园放学，妈妈又迟到了。小芽蹲在水洼边，发现水里倒映的竟是晴天，一团蒲公英绒毛从倒影里浮上来——絮絮。红绿灯变成灯笼，汽车变成打呼噜的甲虫，雨伞像水母一样飞上天。妈妈跑来道歉，絮絮偷偷钻进小芽的雨衣帽子：「你勇敢一点，我就会长大一点。」

### 第二集 · 会呼吸的老楼
周末去外婆家。老楼会呼吸、会眨眼，屋顶菜园里风是甜的。小芽在墙上看见一个红红的、流着「眼泪」的大字，以为是怪兽。外婆蹲下来告诉她：那是「拆」，老楼要搬家了。夜里，老楼困倦地说「老东西总要让路」，小芽握紧拳头：「我会保护你！」

### 第三集 · 灰雾来了
灰雾从城市里涌出来，所到之处颜色全被吃掉。妈妈在电话和医院单据里崩溃，对小芽吼了一句。絮絮缩成一个棉花球。灰先生俯身说「小孩子懂什么」。小芽掏出蜡笔在空中画——红色是外婆的番茄，黄色是她的雨衣——颜色像潮水一样涌回来。第二天，铁犀牛开到老楼前，小芽张开双臂挡住它；絮絮在她的勇气里猛然长成了巨大的模样。

### 第四集 · 铁犀牛与外婆的窗
外婆住进医院。小芽骑着絮絮飞过整座发光的城市，要打败铁犀牛。可驾驶室里的叔叔给她看女儿的照片：「叔叔也不想拆。」铁犀牛流下生锈的眼泪：「我也只是被派来的。」小芽顺着灰雾一路走到它的源头——医院楼梯间里，妈妈正一个人捂着脸哭。原来灰雾是妈妈的眼泪。小芽抱住妈妈，把黄色的蜡笔塞进她手里：「我把黄色借给你。」

### 第五集 · 风的种子
外婆醒了，举着一朵蒲公英：「它要飞走，才能在别的地方开花。」老楼在最后一天睁开眼睛，笑着说谢谢。絮絮化作一千颗种子散向黎明的城市。第二年春天，新楼盖好了，外婆的番茄搬上了新阳台。小芽蹲在新路面的裂缝旁，那里开出一朵蒲公英，旁边的水洼里，隐约还有一朵鲸鱼形状的云。
> 「大人们看不见的东西，其实一直都在。只要你，愿意蹲下来看。」

## 视觉语言

- **镜头高度**：始终在五岁孩子的眼睛高度（约 1 米），大人和建筑因此显得高大。
- **色彩**：融合段落饱和温暖；对抗段落用灰度（代码里由 `gray` 字段控制从彩色到灰的渐变）；领悟段落回到清澈的黎明色与春天。
- **母题**：水洼（门）、蒲公英种子（离别与延续）、黄色（勇气，小芽的雨衣 → 借给妈妈的蜡笔）。
- **声音**：程序生成的八音盒旋律。温暖段落走 C–Am–F–G，对抗段落转入 Am–F–Em–Am，下雨/起雾时叠加白噪声。

## 制作管线（只用 GPT 生图 + 代码）

```
episodes.js  ──►  tools/export_prompts.py  ──►  prompts/PROMPTS.md（复制到 ChatGPT）
     │                                     └─►  prompts/shots.jsonl
     │
     ├──►  tools/generate_images.py  （OpenAI Images API，角色设定图作参考保持一致）
     │         └─► assets/ep{N}/{镜头}.png  ──►  tools/build_manifest.py ──► assets/manifest.json
     │
     └──►  engine.js（镜头运动 / 粒子 / 灰度 / 字幕 / 配乐 / 无图时的程序绘制）
               ├─► index.html  网页播放器
               └─► tools/render.cjs  ──►  out/ep{N}.mp4
```

所有台词、时长、镜头运动（`cam: [起始缩放, 结束缩放, 横移, 纵移]`）、特效（`fx`）和灰度（`gray`）都写在 `episodes.js` 里，改这一个文件就能重新出片。
